# MOTIVA API (Sprint 4)

API REST em Spring Boot + Spring Data JPA sobre o banco Oracle da Sprint 3.

## Como executar
1. Java 17 e Maven instalados.
2. Defina as variáveis de ambiente `DB_USER` e `DB_PASSWORD` (usuário e senha do Oracle FIAP).
3. `mvn spring-boot:run`

As tabelas e sequences já existem no banco (scripts em `sql/`).
